# Basic Rule-Based Chatbot

A simple chatbot that responds to a small set of predefined messages.

## Requirements
- Python 3.8 or newer
- No external packages

## Run
```bash
python main.py
```

## Example
```text
You: hello
PyBot: Hi! How can I help you?
You: how are you
PyBot: I'm fine, thanks! How are you?
You: bye
PyBot: Goodbye! Have a great day!
```

## Concepts used
Functions, strings, `if/elif/else`, loops, input/output.
